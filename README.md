An industry-grade Machine Learning solution for predicting spot market rates (`posted_rate` in $) for truckload freight, submitted for the **Spotter AI Machine Learning Engineer Assessment**.

---

## 📌 Objective

Predicting freight rates accurately requires balancing spatial geography (origin-destination corridors), temporal seasonality (weekly dispatch cycles), payload weight density, equipment capabilities, and spot market indicators.

This project delivers a complete, modular, and reproducible ML system:
- **Out-Of-Time (OOT) Validation:** Evaluates models on an OOT split (Jan–Aug train vs. Sept–Oct val) mirroring production deployment (Jan–Oct train vs. Nov–Dec val).
- **Zero-Shot Spatial Generalization:** Engineered Haversine distances, route circuity ratios, coordinate deltas ($\Delta\text{lat}, \Delta\text{lon}$), and regional midpoints to effectively handle unseen cities in the validation set.
- **Model Architecture:** Built `FreightEnsembleModel` blending **CatBoost**, **HistGradientBoosting**, and **LightGBM** trained on log-transformed rates (`log1p`).
- **Validation Metrics:** Achieved an **OOT MAE of $127.09**, **MAPE of 5.45%**, **Median AE of $49.99**, and an **R² of 0.8244**.
- **Scorer Verification:** 100% compliant with Spotter AI's official `score.py` verification tool.

## 🔬 Approach & Methodology

### 1. Data Preprocessing & Leakage Prevention
- Audited train and validation datasets for duplicate records, missing values, and extreme outliers.
- Formulated strict leakage boundaries: features are generated without target contamination; city coordinates are mapped without target leakage.

### 2. Feature Engineering
Built inside `src/features.py`, `FreightFeatureEngineer` computes:
- **Spatial Features:** Haversine Great Circle distance, route circuity ratio (`distance / (haversine_dist + 1)`), coordinate deltas ($\Delta\text{lat}, \Delta\text{lon}$), and midpoint centroid.
- **Payload Density:** `weight_per_mile` and log-scaled payload metrics.
- **Temporal & Seasonality:** Day of week, day of year, quarter, and cyclical sine/cosine trigonometric transformations.
- **Market & Demand:** Interaction terms (`distance * market_index`, `market_index * quote_signal`).
- **Equipment Encodings:** One-hot encoding for Dry Van, Reefer, and Flatbed.

### 3. Out-Of-Time (OOT) Validation Strategy
- **OOT Train:** Jan 1, 2025 – Aug 31, 2025 (38,477 loads)
- **OOT Validation:** Sept 1, 2025 – Oct 31, 2025 (9,523 loads)

### 4. Models Evaluated & Final Architecture
Benchmarked Ridge Regression, Random Forest, Extra Trees, XGBoost, LightGBM, HistGradientBoosting, and CatBoost.
The final production model is **`FreightEnsembleModel`**, an ensemble blend trained on log-transformed rates ($\log(1+y)$):
$$\hat{y}_{ensemble} = 0.45 \cdot \hat{y}_{CatBoost} + 0.45 \cdot \hat{y}_{HistGBM} + 0.10 \cdot \hat{y}_{LightGBM}$$

### 5. Benchmark Performance (OOT Split)
| Model Architecture | Target Transform | MAE ($) | RMSE ($) | MAPE (%) | Median AE ($) | R² Score |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: |
| Baseline (Ridge) | Raw | $194.43 | $659.45 | 10.40% | $120.43 | 0.8133 |
| LightGBM | Log1p | $139.20 | $642.29 | 6.04% | $59.92 | 0.8229 |
| HistGradientBoosting | Log1p | $128.03 | $639.58 | 5.49% | $48.33 | 0.8243 |
| CatBoost | Log1p | $127.99 | $639.31 | 5.70% | $52.91 | 0.8245 |
| **FreightEnsembleModel** | **Log1p** | **$127.09** | **$639.54** | **5.45%** | **$49.99** | **0.8244** |

## ⚡ Reproduction Guide

### 1. Environment Setup
```bash
# Create and activate Python 3.10+ virtual environment
python3 -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt
```

### 2. Dataset Placement
Place the assessment raw CSV datasets in the root folder of this submission directory:
- `train-test.csv` (Development data, 48,000 loads)
- `validation.csv` (Validation data, 12,000 loads)
- `validation-predictions-template.csv` (Submission template)
- `december-chart-inputs.csv` (December 31-day input file)

### 3. Model Training
To retrain the model and evaluate on the OOT split:
```bash
python -m src.train
```

### 4. Generating Predictions
To generate `outputs/validation_predictions.csv` and populate `december-chart-inputs.csv`:
```bash
python -m src.predict
```

### 5. Running Official Spotter Scorer
To run the official Spotter AI validation scorer:
```bash
python score.py --predictions outputs/validation_predictions.csv --december-predictions december-chart-inputs.csv
```

### 6. Interactive Jupyter Notebook
To run the end-to-end interactive notebook:
```bash
jupyter notebook notebooks/Freight_Rate_ML_Assessment.ipynb
```
